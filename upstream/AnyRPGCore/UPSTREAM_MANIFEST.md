## What was intentionally left out

Binary media and Unity-serialised scene/prefab data:

```
*.fbx  *.png  *.jpg  *.tga  *.psd  *.exr
*.wav  *.mp3  *.ogg
*.anim  *.controller  *.overrideController  *.mask  *.mixer
*.unity  *.prefab  *.asset  *.mat  *.physicMaterial  *.spriteatlas
*.meta (12,000+ GUID sidecars — regenerated by Unity on import)
```

Reasons: the complete tree is 1.2 GB / 22,916 files, GitHub blocks files above
100 MB, and a repository snapshot of that size is not useful for code review.
`*.meta` files are regenerated automatically the first time Unity imports the
project.

## Restoring the complete project

```bash
git clone https://github.com/AnyRPG/AnyRPGCore.git
```

Then open the cloned folder with Unity 6000.3.10f1. To merge back into this
copy, drop the missing binaries into the same relative paths; the folder
structure here already matches upstream one-for-one.

## Note

AnyRPG is a Unity project and needs the Unity Editor to build. It cannot be
compiled with the JDK/Android toolchain used by this repository's `tools/`
scripts, which is why the shipped game (Last Star) is a native Java/OpenGL ES
project instead.
